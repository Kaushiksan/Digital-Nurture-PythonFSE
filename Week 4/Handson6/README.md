# Hands-On 6

## Topics Covered

- pytest
- Fixtures
- Parameterized Tests
- HTML Reports
- Screenshot on Failure
- Selenium WebDriver

## Install

```bash
pip install -r requirements.txt
```

## Run Tests

```bash
pytest
```

## Generate HTML Report

```bash
pytest --html=report.html --self-contained-html
```

## Expected Output

- 3 Simple Form tests (parameterized)
- Checkbox test
- Dropdown test
- HTML report generated
- Screenshot captured on failure
